BIO

Kia ora. I am Manoj Kumar Panthi, a student on the ITWD6.408 Advanced Internet and Web Development paper at EIT. I built this portfolio to practise real web pages: semantic HTML, CSS layout, forms, JavaScript demos and a small shop that stores accounts in a Supabase users table.

I am taking this paper to get stronger at CSS Grid and Flexbox, accessible forms, and using APIs so a static site can read and write data. I hope to finish with pages I can explain in a walkthrough and reuse in later projects.

Outside class I like football, cooking, and taking photos around Hawke’s Bay. I also enjoy turning assignment briefs into working pages and helping classmates debug layout issues.

MY WEB TECHNOLOGIES

TOP 5 WEB TECHNOLOGIES I USE:

  1. HTML5 for page structure, landmarks, forms and the markup on every page of this site.
  2. CSS3 for layout (Grid and Flexbox), colour, spacing and the mobile navbar.
  3. JavaScript for slideshows, comments, the shop dashboard and sign in against Supabase.
  4. Visual Studio Code as my editor, with browser tools to check layout and forms.
  5. Supabase as the hosted Postgres database for the Demo 4 users table.
