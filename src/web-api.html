JSON Rules

JSON (JavaScript Object Notation) is a lightweight format for storing and sending data. These rules keep a JSON document valid.

Rule 1: Objects use curly braces

An object is wrapped in curly braces and holds comma-separated name/value pairs.

Code sample: {"name": "Manoj", "paper": "ITWD6.408"}

Rule 2: Keys must be double-quoted strings

Every key is a string in double quotes. Single quotes are not allowed in JSON.

Code sample: {"city": "Napier"}

Rule 3: Values have allowed types

A value may be a string, number, object, array, true, false or null. Functions and undefined are not allowed.

Code sample: {"score": 80, "passed": true}

Rule 4: Arrays use square brackets

An array is an ordered list of values wrapped in square brackets.

Code sample: ["HTML", "CSS", "JavaScript"]

Rule 5: No trailing commas

Do not leave a comma after the last item in an object or array.

Code sample: {"id": 1, "active": true}

Rule 6: No comments and one top-level value

A JSON file is a single object or array. Comments are not allowed in strict JSON.

Code sample: [{"firstName": "Manoj"}]
